# Clarify First 用户使用示例

## 这个 Skill 适合什么

`clarify-first` 适合“现在只有一个大概想法，希望通过逐步对话看清真正需求，再获得方案”的场景。它可以用于产品构思、内容策划、技术选型、学习计划、流程改进、采购比较和其他存在动机、假设、证据或取舍的问题。

该 Skill 只支持显式调用。请使用 `$clarify-first`，或通过当前宿主提供的 Skill 入口选择它。启用后，Agent 每轮只问一个简短、中立的问题，并等待你的回答；当前回答仍不清楚时，它会继续澄清同一问题，不提前跳到下一项。

## 使用前准备

- 最少只需准备一句问题或一个尚未成形的想法，不需要先填写完整表单。
- 已知时可以补充使用者、当前做法、时间、预算、已有材料和不能触碰的边界。
- 某个问题暂时说不清时，可以描述一个具体经历、反例或可接受边界，帮助继续澄清。
- 整个澄清阶段不会提供草案、推荐或行动步骤；只有你明确确认需求摘要后，Agent 才会给出方案。

## 快速开始

下面是最短的可复制输入：

```text
$clarify-first

我想做一个面向新用户的产品介绍页，但现在还没有想清楚具体需求。
请每次只问我一个问题，等我确认需求摘要后再给方案。
```

**预期交付**

第一轮会简短复述当前理解，然后只提出一个最影响需求判断的问题。你回答后，Agent 才继续下一轮；如果回答仍有歧义，它会围绕同一点追问。所有关键内容清楚后，Agent 会单独提交需求摘要并询问是否准确、完整，不会在同一条回复中附带方案。只有你明确确认摘要后，下一次回复才会提供方案。

## 常见场景

### 场景一：把模糊的产品想法逐步说清

**可复制输入**

```text
$clarify-first

我想给团队做一个内部知识库。请用苏格拉底式提问帮助我检验真实动机和关键假设，每次只问一个问题。
```

**预期交付**

Agent 不会一开始罗列工具或问题清单。它会从一个最关键的点开始，例如要改变的现状；只有这一点清楚后才继续。提问用于检验动机、事实和假设，不会暗示应该购买某个产品或采用某条路线。

### 场景二：在比较选项前明确决策标准

**可复制输入**

```text
$clarify-first

我们想换项目管理工具。请先逐步澄清实际问题、证据和取舍；需求摘要经我确认前，不要给工具建议。
```

**预期交付**

Agent 会一次确认一个决策条件。若“协作效率低”仍然抽象，它会继续追问具体表现或证据，不会马上跳到预算、迁移或产品功能。需求摘要未获明确确认前，不会出现候选工具、推荐倾向或迁移步骤。

### 场景三：澄清技术需求而不预设实现

**可复制输入**

```text
$clarify-first

我想给现有系统增加搜索功能。请每轮只问一个中立问题，先帮助我明确业务目标和成功标准，再整理需求摘要。
```

**预期交付**

问题会围绕真实搜索场景和可观察结果逐步展开，不会把某个搜索引擎、架构或指标包装成问题来诱导选择。用户确认摘要前，Agent 不会给技术路线或实施步骤。

### 场景四：回答仍然含糊

**可复制输入**

```text
$clarify-first

我想制定一个三个月的学习计划。我有时会回答得很抽象；如果当前回答仍不清楚，请继续追问同一点，不要提前问下一项，也不要替我选择答案。
```

**预期交付**

当你回答“想尽快学会”时，Agent 会用一个更具体的问题继续澄清“学会”的可观察标准，而不是立即转问每周时间或推荐学习路径。每次回复仍然只包含一个问题。

### 场景五：先确认摘要，再进入方案

**可复制输入**

```text
$clarify-first

我在规划一次用户访谈。请逐步帮我检验目标、现有证据和关键取舍。全部澄清后先单独给需求摘要，等我明确确认后再给方案。
```

**预期交付**

Agent 完成澄清后只提交需求摘要，并问一个确认问题。若你更正摘要，它会先处理这项更正并重新确认；只有收到“确认”“准确”或同样明确的答复后，才会在下一轮输出访谈方案。

## 不适用场景

- “某个术语是什么意思”或“某个确定事实是什么”等答案唯一的简单问答；
- 需求、范围、文件和验收已经完整，只需要立即执行的任务；
- 希望立即获得草案、建议或行动步骤，不愿先确认需求摘要；
- 希望 Agent 不经讨论就购买、发送、删除、提交或修改外部系统；
- 用反复提问替代紧急安全提示、专业诊断或必要的人工判断；
- 只想自由发散灵感，并不希望收敛到清晰需求。

`clarify-first` 交付的是经过明确确认的需求摘要及后续方案。若下一步需要真正修改文件、操作外部服务或产生其他副作用，请在需求确认后另行明确授权。
