# 字幕转中文公众号文章

## 目标与默认值

把字幕转换为一篇可以直接编辑发布的中文公众号文章，而不是字幕摘要或逐句译稿。

- 默认读者：愿意理解主题的普通中文读者。
- 默认文体：编辑转述体；可识别讲者时保留归因，不可识别时不虚构身份。
- 默认篇幅：随有效信息量自适应。
- 默认格式：Markdown，包含一个主标题、导语、分节正文和结语。
- 默认边界：只使用字幕提供的信息，不联网补写背景、数据、事实或案例。

## 工作流

1. **确认输入**：接收一个 SRT、WebVTT、ASS/SSA、LRC、TXT 或 Markdown 文件。文件不可访问、为空或格式不受支持时，停止并说明问题。
2. **规范化字幕**：在 Skill 目录执行 `python3 scripts/normalize_subtitle.py <input> -o <temporary-output>`。需要覆盖自动识别时使用 `--encoding` 或 `--format`。编码存在歧义时不得猜测，要求用户明确指定 `--encoding`。
3. **检查清洗结果**：确认正文非空、顺序合理、讲者信息仍可辨认。脚本只清理确定性结构，不把其 stderr 诊断写进文章。
4. **判断语言**：按有效语义判断中文字幕、外语字幕或混合字幕。零散产品名、代码或惯用术语不单独构成混合语言。
5. **建立中文语义底稿**：中文字幕直接提取语义；外语字幕先准确翻译；混合字幕只翻译外语部分。记录主题、观点、论证、案例、数字、限定条件、讲者归因和歧义项。
6. **处理长字幕**：可以按语义段分块读取，但每块只更新同一份全局底稿。全部读取后统一消歧、去重和排序，禁止把各块摘要串接为正文。
7. **重组文章**：确定单一主线，按读者理解顺序而非字幕时间轴组织内容。删除口头禅和无信息重复，保留支撑结论所需的观点、论证、案例、数字、反例与限制。
8. **生成成品**：使用文章模板写一个克制、准确的标题，随后写导语、语义分节正文和结语。只输出完整文章。
9. **最终检查**：逐项执行质量检查清单。发现编造、模态改变、错误归因、关键限定条件遗漏或局部摘要拼接时，必须修订后再交付。

## 语言与忠实度规则

- 中文字幕直接文章化，不先改写成另一份逐句稿。
- 外语先形成准确、自然的中文语义底稿，再据此写作，不把逐句译文直接当正文。
- 混合语言只翻译实质性外语内容；公司名、产品名、项目名、代码和必要术语保留官方形式。
- 保持数字、单位、日期、比较关系、否定、时态、因果和范围不变。
- 不把“可能”“计划”“尝试”“尚未验证”改成“已经”“必然”或确定事实。
- 不把讲者的判断、预测或经验包装成客观事实；多讲者内容不得混淆立场。
- 字幕含混时不得猜测。关键歧义保留原文或明确不确定性；非关键噪声可以省略。

## 输出要求

- 输出一篇完整、连贯、易读的中文公众号文章，而不是处理日志、逐句译文、摘要列表或质量报告。
- 只保留一个主标题；不用标题候选列表或夸张标题。
- 段落围绕一个清晰意思展开，分节服务于论证，不机械对应字幕片段。
- 删除模板占位符、内部底稿、脚本诊断和无法支撑的说明。
- 用户明确要求其他篇幅、受众、口吻或附加材料时，优先遵循用户要求，但仍执行忠实度与事实边界规则。
