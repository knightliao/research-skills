# 疑似机翻字幕的术语消歧示例

本示例使用虚构内容，只演示语境判定与术语统一，不提供完整公众号文章。

## 输入片段

```text
代理会先制定计划，再调用工具并运行实验。
我们的 Code Agent 负责修改仓库里的代码。
网页流量通过代理服务转发。
这位代理代表作者与出版社谈判。
这个 model 使用训练数据更新参数。
那位 fashion model 正在准备拍摄。
```

## 内部术语簿

| 字幕表面用词 | 语境含义 | 选定译法 | 例外或说明 |
| --- | --- | --- | --- |
| 代理 | 能规划、调用工具和执行实验的 AI 系统 | 首次“AI Agent（智能体）”，后文“智能体” | 不影响网络代理和代理人的译法 |
| Code Agent | 固定技术名称 | Code Agent | 首次可补充“编程智能体”说明，不拆译名称 |
| 代理服务 | 网络转发组件 | 代理服务 | 不改成“智能体服务” |
| 代理 | 受托代表作者谈判的人 | 代理人 | 根据委托关系消歧 |
| model | 机器学习系统 | 模型 | 根据训练数据和参数语境消歧 |
| fashion model | 时尚行业从业者 | 模特 | 不与机器学习模型合并 |

术语簿是内部底稿，不进入最终文章。

## 校准后的表达

文中提到的 Code Agent 专门负责修改仓库代码。固定名称中的 `Agent` 不占用通用概念的首次解释；后文第一次泛指这类系统时，仍应写成“AI Agent（智能体）可以先制定计划，再调用工具并运行实验”。网页流量仍由代理服务转发，而代表作者与出版社谈判的是代理人。

同一个英文词也可能随领域变化：使用训练数据更新参数的 model 是“模型”，准备拍摄的 fashion model 则是“模特”。因此，术语统一不是全文替换，而是先确定每次出现时的语境含义。
