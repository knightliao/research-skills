# 质量检查清单

## 输入与处理

- [ ] 已读取完整可用字幕，没有只处理开头或某几个片段。
- [ ] 格式和编码已经可靠识别；编码歧义没有被猜测。
- [ ] 时间轴、序号、样式和机械重复已清理，正文顺序与讲者信息仍正确。
- [ ] 已分别判断表层语言和中文文本状态；表面为中文时也检查了疑似机翻、译制和术语漂移。
- [ ] 长字幕使用统一全局底稿，而不是多个局部摘要。

## 翻译

- [ ] 自然中文字幕没有被多余翻译或机械逐句重写；疑似机翻或译制中文已经过语义和术语校准。
- [ ] 外语内容先形成中文语义底稿，混合字幕只翻译外语部分。
- [ ] 术语密集或译法不稳定时已建立内部术语簿，并按用户要求、官方形式、领域惯例、英文解释和歧义保留的优先级处理。
- [ ] 只有上下文唯一支持的高置信度术语被规范化；中低置信度候选没有进入选定译法或被静默补成字幕未提供的项目名、人物名和原文术语。
- [ ] 没有机械全局替换同形异义词；专有名词和术语符合各自语境，必要的官方名称仍保留。
- [ ] 标题、导语、分节标题和正文的术语译法一致；AI 主题的最终 Markdown 第一次泛指此类系统时写作“AI Agent（智能体）”，内部术语簿及固定名称中的出现没有占用首次解释，后文才使用“智能体”。
- [ ] 数字、单位、日期、否定、时态、比较和条件与字幕一致。
- [ ] 没有为字幕未提供年份的日期补写相对年份或绝对年份。
- [ ] 关键歧义被保留或标明，没有猜测性补全。

## 忠实度与事实边界

- [ ] 核心观点、论证、案例、反例、数字和限定条件均有体现。
- [ ] “可能、计划、尝试、尚未验证”等没有被改成确定事实。
- [ ] 讲者观点、预测和经验没有被包装为客观事实。
- [ ] 多讲者的身份和立场没有混淆。
- [ ] 没有联网补造背景、数据、案例、身份或结论；用户访谈的头像检索只用于配图确认，检索结果没有反向进入正文。
- [ ] 没有为了行文顺畅创造原字幕不存在的因果关系。

## 文章与交付

只检查与本次交付意图相符的项目；图片预览不需要满足正式发布包的 complete、manifest 和固定资产检查。

- [ ] 已先判断本次是“只修改源稿、只预览图片、创建发布包、继续 incomplete 包或只读查询”，没有把图片预览误当成正式打包。
- [ ] 全文只有一个清晰主线和一个主标题。
- [ ] 标题、导语、分节正文和结语结构完整，篇幅与信息量匹配。
- [ ] 正文按语义重组，不沿时间轴机械拼接，也不拼接局部摘要。
- [ ] 段落自然、指代明确、过渡合理，列表使用克制。
- [ ] 已删除所有模板占位符、内部底稿、内部术语簿、逐句译文、处理日志和质量说明。
- [ ] 主标题已单独写入 `title.txt`；HTML 正文没有重复主标题，二级标题稳定放大、加粗。
- [ ] 可编辑源稿位于文章包之外，且不包含任何图片引用；包内 `article.md` 是本次发布的不可变快照。
- [ ] `mode` 明确为 `cover-only` 或 `body-images`。默认 `expected_body_image_count` 为 0；只有用户显式要求时才启用正文配图。
- [ ] body-images 模式的 `illustration-plan.json` 已冻结，图片编号连续、用途非空、章节存在，段落位置只统计当前章节普通段落。
- [ ] `image-prompts.md` 默认只包含一个非空 cover 提示词；启用正文配图时再包含数量一致、角色连续的 body 提示词。
- [ ] 已基于最终标题、导语、各节主旨和结语形成内部视觉简报，包含核心主题、中心张力、文章语气、允许的视觉隐喻和禁止的视觉推断，而不是只看标题或人物身份。
- [ ] 每张图至少有两项可见的“文章线索 → 视觉表达”映射；横版裁切、人物移位、留白或通用科技背景没有被单独当作内容适配。
- [ ] 图片通过“换标题测试”：不能不改画面就自然套用到同领域但观点不同的文章；抽象隐喻没有伪装成真实物体或暗示字幕未提供的具体事实。
- [ ] 若文章是用户访谈，已从明确文本线索唯一确认核心受访者，没有把主持人、同名者或推测身份当作主人公；无法确认时已暂停图片流程并请求用户指定。
- [ ] 用户访谈头像来自用户提供素材、人物本人公开主页、所属组织官方人物页或可信活动人物页，已记录来源与获取日期；来源、使用权限或人物对应关系不清时没有继续安装。
- [ ] 用户访谈封面以真实头像微修结果为主视觉；内容相关的色彩、纹理和抽象隐喻符合内部视觉简报，没有改变人物身份特征、做人脸替换或新增文字、Logo 与虚构纪实场景。
- [ ] 若只预览图片，成品保留在宿主图片工具默认目录或仓库之外的临时路径；没有在仓库中创建 `output/`、`images/` 等通用目录，也没有向 `reports/subtitle-to-wechat-article/` 写入散落图片；交付说明明确写出“未创建发布包”。
- [ ] 若创建或继续发布包，正式图片全部通过 `add-image` 安装到固定目标；没有把生成器默认文件或临时文件手工复制进包内。
- [ ] `cover.png` 是文章包中的真实、非空、有效横版 PNG；启用正文配图时，全部 `images/body-NN.png` 也必须通过相同资源校验。没有占位图、远程图或额外图片。
- [ ] `article.md` 与可选 `illustration-plan.json` 的 SHA-256 均与 init 时一致；manifest 当前错误为空且状态为 complete。
- [ ] `publish-guide.md` 已列出标题、封面和 HTML 用法；仅在启用正文配图时列出每张正文图的章节和人工插入位置。
- [ ] complete 包中没有内部临时文件、空保留文件或未被 manifest 记录的正式图片。

以下任一问题都必须阻止交付并触发修订：编造内容、改变模态或完成状态、错误归因、漏掉影响结论的限定条件、将局部摘要直接拼成正文、内容—视觉映射缺失、图片未通过换标题测试，或预览图被错误写入仓库通用目录。对于正式发布包，文章或插图计划哈希变化、必需提示词或真实图片不完整、图片未通过 `add-image` 安装、已启用资源校验失败、manifest 仍为 incomplete 也必须阻止交付。文章修改、模式切换或计划变化必须创建新版本，不能修补旧包。
