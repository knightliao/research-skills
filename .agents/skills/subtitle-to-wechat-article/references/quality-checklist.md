# 质量检查清单

## 输入与处理

- [ ] 已读取完整可用字幕，没有只处理开头或某几个片段。
- [ ] 格式和编码已经可靠识别；编码歧义没有被猜测。
- [ ] 时间轴、序号、样式和机械重复已清理，正文顺序与讲者信息仍正确。
- [ ] 长字幕使用统一全局底稿，而不是多个局部摘要。

## 翻译

- [ ] 中文字幕没有被多余翻译或机械逐句重写。
- [ ] 外语内容先形成中文语义底稿，混合字幕只翻译外语部分。
- [ ] 专有名词和术语译法一致，必要的官方名称仍保留。
- [ ] 数字、单位、日期、否定、时态、比较和条件与字幕一致。
- [ ] 关键歧义被保留或标明，没有猜测性补全。

## 忠实度与事实边界

- [ ] 核心观点、论证、案例、反例、数字和限定条件均有体现。
- [ ] “可能、计划、尝试、尚未验证”等没有被改成确定事实。
- [ ] 讲者观点、预测和经验没有被包装为客观事实。
- [ ] 多讲者的身份和立场没有混淆。
- [ ] 没有联网补造背景、数据、案例、身份或结论。
- [ ] 没有为了行文顺畅创造原字幕不存在的因果关系。

## 文章与交付

- [ ] 全文只有一个清晰主线和一个主标题。
- [ ] 标题、导语、分节正文和结语结构完整，篇幅与信息量匹配。
- [ ] 正文按语义重组，不沿时间轴机械拼接，也不拼接局部摘要。
- [ ] 段落自然、指代明确、过渡合理，列表使用克制。
- [ ] 已删除所有模板占位符、内部底稿、逐句译文、处理日志和质量说明。

以下任一问题都必须阻止交付并触发修订：编造内容、改变模态或完成状态、错误归因、漏掉影响结论的限定条件、将局部摘要直接拼成正文。
