# Markdown 阅读图片使用示例

## 适用场景

当你已经有一段 Markdown，希望不改变文字内容，只把它排成适合手机阅读、分享或存档的 PNG 图片时使用本 Skill。默认生成一张连续长图；明确要求分页、多张图片或固定页面时，才改为连续编号的分页图片。

## 使用前准备

- 直接粘贴完整 Markdown，或提供一个可读取的 UTF-8 `.md` 文件路径；
- 如有固定交付位置，提供一个尚不存在的输出目录；
- 确认内容不包含表格、任务列表、Markdown 图片、原始 HTML、嵌套列表或嵌套引用。

## 可复制输入：快速开始

```text
$markdown-to-image

请把下面的 Markdown 忠实排版成适合手机阅读的一张长图。不要改写内容，输出到新目录；完成后展示长图并告诉我实际尺寸和文件路径。

# 为什么清晰比华丽更重要

一份容易理解的说明，通常来自 **稳定的层级** 和足够的留白。

- 先说明结论；
- 再展开依据；
- 最后给出下一步。

> 视觉设计应服务于阅读，而不是遮挡内容。
```

## 从文件生成

```text
$markdown-to-image

把 `<Markdown 文件路径>` 默认排版成一张长图，输出到 `<尚不存在的目录>`。保持原文顺序和措辞，遇到不支持语法时停止并告诉我具体行号。
```

## 显式分页

```text
$markdown-to-image

把下面的 Markdown 忠实分页为多张 `1080×1440` PNG，不要改写内容。输出到一个新目录，完成后展示第一页并列出全部文件路径。

# 一篇需要分页分享的长文

<完整 Markdown 正文>
```

只有明确提出“分页”“多张图片”或固定 `1080×1440` 页面时才使用此模式。未提出时保持默认长图；长图预计超过 `30000px` 时会停止并建议用户显式改用分页。

## 包含代码的输入

````text
$markdown-to-image

把下面的技术说明排版成图片。保留行内代码、代码块、链接文字和 URL，不要摘要。
````

## 预期交付

- 一个新的输出目录；
- 默认模式只生成 `long-image.png`，宽度为 `1080px`、高度按内容增长且不显示页码；
- 显式分页模式生成从 `page-001.png` 开始的连续 PNG，全部为 `1080×1440`；
- 未明确要求分页时，无论长短都保持单张长图；
- 实际页数、输出目录和全部绝对路径；
- 明确说明没有改写或补充原文。

## 不适用场景

- 希望先摘要、润色、翻译或重写 Markdown；
- 希望制作带复杂插画、品牌素材或自由构图的营销海报；
- 输入依赖表格、任务列表、嵌套列表、原始 HTML 或 Markdown 图片；
- 希望联网下载链接内容、图片或字体；
- 需要可编辑的演示文稿、Word、PDF、HTML 或网页，而不是 PNG 图片。

遇到不支持的 Markdown 时，Skill 会停止并报告行号，不会忽略内容或把结构静默降级成普通文字。输出目录已存在时也会停止，避免覆盖已有图片。
