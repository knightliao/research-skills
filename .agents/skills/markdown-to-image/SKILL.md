# Markdown 阅读图片

把 Markdown 原文确定性排版为浅色 PNG；默认生成单张 `1080px` 宽长图，按明确要求才生成 `1080×1440` 连续页面。不摘要、不改写，也不让图片模型绘制文字。

## 调用边界

- 只有用户显式选择或调用本 Skill 时才使用。普通 Markdown 编辑、润色或解释请求不得触发。
- 接受当前消息中粘贴的 Markdown，或一个可读取的 UTF-8 `.md` 文件。
- 只输出浅色 PNG；默认生成一张长图。用户明确要求“分页”“多张图片”或“固定页面”时才使用分页模式。
- 不获取远程资源，不解析图片，不使用网络或生成式图片工具。

## 用户使用示例

当用户询问如何调用、需要可复制输入、未提供 Markdown，或需要确认支持的语法与输出目录时，按需读取：

- [用户使用示例](examples/usage.md)

不要在每次执行时默认加载使用示例。

## 运行资源

| 资源 | 何时使用 | 固定动作 |
| --- | --- | --- |
| [渲染契约](references/rendering-contract.md) | 每次渲染前 | 确认支持语法、模式选择、视觉和失败行为，不自行扩展 Markdown 子集。 |

## 工作流

1. **确认输入**：接收粘贴的 Markdown 或 UTF-8 `.md` 文件。输入缺失、为空、不可读或编码无效时停止。
2. **确认模式与交付位置**：未指定模式时输出单张长图；明确要求分页、多张图片或固定 `1080×1440` 页面时使用 `--paginate`。用户指定目录时使用 `-o`；未指定时允许 CLI 自动选择 `reports/markdown-to-image/<stem>-vN/`。不得输出到 Skill 目录内。
3. **安全准备粘贴文本**：优先将原文写入任务临时 Markdown 文件，或通过 CLI 的 `-` 从 stdin 传入；不得把用户文本插入 shell 命令字符串。
4. **检查渲染器**：确认 `rsvg-convert` 可执行；用户提供了替代路径时使用 `--renderer`。不存在时停止并报告安装或路径要求，不静默降级为 SVG。
5. **执行渲染**：以 Skill 目录定位脚本，从任务工作区运行命令，确保自动输出目录不落入 Skill。默认长图运行：

   ```text
   python3 scripts/render_markdown_image.py <输入.md> [-o <新输出目录>]
   ```

   显式分页运行：

   ```text
   python3 scripts/render_markdown_image.py <输入.md> --paginate [-o <新输出目录>]
   ```

   stdin 模式将输入改为 `-`。输出目录必须是新目录；不得使用覆盖或删除已有结果的捷径。
6. **处理校验错误**：遇到不支持语法时，保留 CLI 给出的行号和稳定错误 code，请用户调整输入或明确改用其他工作流。不得忽略、删除或当普通文字吞掉该部分。
7. **检查产物**：确认 CLI 成功。默认模式检查只有 `long-image.png`、宽度为 `1080px` 且实际高度与 CLI 校验一致；分页模式检查页码连续且每张图片均为 `1080×1440`。宿主支持预览时展示长图或第一页；多页结果同时报告页数、输出目录和全部文件路径。
8. **交付**：说明内容未被改写，并报告实际绝对路径。不得把临时 SVG、Markdown 中转文件或失败半成品当作交付物。

## 输出要求

- 默认模式只输出 `long-image.png`，宽度固定为 `1080px`，高度至少 `1440px` 并随内容增长，最高 `30000px`，不显示页码。
- 分页模式文件名固定为 `page-001.png`、`page-002.png`……，编号从 1 连续递增；所有页面均为 `1080×1440`。
- 链接同时保留链接文字与目标 URL；代码、引用和列表的语义层级可见。
- 长图或多页内容不得丢失、重复或改变顺序；页脚页码只在显式分页且超过一页时出现。
- 最终回复提供长图实际尺寸或分页页数、输出目录、文件路径，以及任何未执行的目视检查。

## 硬性规范

- 忠实排版，不更换标题、不改写句子、不校正事实、不补充内容。
- 不使用图片生成模型渲染文字，不访问网络，不添加第三方 Python 依赖。
- 单张长图超过 `30000px` 高度上限时必须停止并建议显式使用分页模式，不得缩小文字或静默拆图。
- 不覆盖已有目录或图片；失败时不得留下部分页面。
- 不手工猜测不支持语法的显示方式；以 CLI 错误为准停止。
- 不把 SVG 中间文件作为成功结果。

## 完成前检查

- [ ] 输入是否完整且为 UTF-8 Markdown？
- [ ] 是否只包含渲染契约支持的语法？
- [ ] 是否使用新输出目录且未覆盖已有文件？
- [ ] CLI 是否返回成功，文件数量、尺寸和路径是否与实际一致？
- [ ] 默认长图是否为 `1080px` 宽且高度通过校验，或显式分页是否均为 `1080×1440`？预览图是否可读且无裁切？
- [ ] 是否明确说明原文未被改写，并提供全部绝对路径？
