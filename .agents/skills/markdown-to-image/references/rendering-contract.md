# Markdown 图片渲染契约

## 输入与支持语法

输入必须是非空 UTF-8 Markdown。第一版支持：

- ATX 一级至六级标题；
- 普通段落、软换行和使用两个尾随空格或反斜线声明的硬换行；
- 单层无序和有序列表；
- 单层块引用；
- 粗体、斜体、行内代码和 Markdown 链接；
- `---`、`***` 或 `___` 分隔线；
- 使用至少三个反引号或波浪线的围栏代码块，可带语言标签。

图片、表格、任务列表、原始 HTML、嵌套列表、嵌套引用和缩进代码块必须报错并给出源行号。不得联网读取链接或其他资源。链接在静态图片中显示链接文字，并以弱化样式附带原始目标 URL。

## 输出模式

- 默认单张长图模式：未指定模式时输出 `long-image.png`，宽度固定为 `1080px`，高度按内容增长且不显示页码。
- 显式分页模式：只在用户明确要求“分页”“多张图片”或固定 `1080×1440` 页面时启用 `--paginate`；文件名为 `page-001.png`、`page-002.png`……。
- 单张长图高度至少为 `1440px`，最高为 `30000px`。预计高度超限时返回 `LONG_IMAGE_TOO_TALL`，建议显式改用分页；不得缩小字号、裁切内容或静默改为分页。

## 视觉规范

- 默认长图画布宽度固定为 `1080px`、高度自适应；分页画布固定为 `1080×1440`；内容左右边距均为 `88px`。
- 背景使用暖白色，正文使用深灰色，强调色使用低饱和蓝绿色。
- 正文基准字号 `38px`、行高 `60px`；标题按层级放大并加粗。
- 中文优先使用系统中文无衬线字体，代码使用系统等宽字体；不打包字体资产。
- 引用使用左侧强调线，代码块使用圆角浅灰底，列表标记与正文对齐。
- 所有用户文本必须经过 XML 转义，不能形成 SVG 标签或属性。

字宽使用保守的 Unicode 估算：全角和宽字符按一个字号宽度，拉丁字母、数字、空格和标点按各自比例计算。单个长英文词或 URL 超出行宽时按字符拆分，优先避免右侧裁切。

## 分页规则

- 第一页和后续页使用相同画布；内容区域位于 `y=88` 至 `y=1320`。
- 内容能放入一页时只输出 `page-001.png`，不显示页码。
- 标题尽量与下一块至少两行内容同页；页尾空间不足时整体移到下一页。
- 段落必须拆分时，尽量保证页尾和下一页都至少保留两行，避免单行孤行。
- 列表项、引用和代码块可以跨页；后续片段保持缩进、引用线或代码背景。代码续页显示“代码（续）”。
- 多页在底部显示 `当前页 / 总页数`。不得因为分页丢失、重复或重排原文。

## 单张长图规则

- 内容从 `y=88` 开始连续排列，底部至少保留 `88px` 留白；短内容仍保持 `1440px` 最小高度。
- 标题、段落、列表项、引用和代码块不得因页面高度拆分；所有块保持原有顺序和视觉语义。
- 长图不显示分页页码。不得因为连续布局丢失、重复或重排原文。

## CLI 与原子交付

```text
python3 scripts/render_markdown_image.py INPUT [-o OUTPUT_DIR] [--renderer PATH] [--paginate]
```

- `INPUT` 为文件路径或 `-`；`-` 从 stdin 读取。
- 显式 `OUTPUT_DIR` 已存在时立即失败。未指定时，在当前目录的 `reports/markdown-to-image/` 下选择递增的 `-vN` 目录。
- 默认从 `PATH` 查找 `rsvg-convert`；`--renderer` 可指定其他路径或命令名，但仍须兼容 `rsvg-convert` 参数。
- 未指定 `--paginate` 时只生成 `long-image.png`；指定后按固定页面连续编号输出。
- 先完成 Markdown 解析和对应模式的 SVG 布局，再在输出目录同级的临时目录渲染。
- 每张 PNG 必须通过签名、数据块边界、CRC、IHDR、IDAT 和 IEND 校验；分页图片校验为 `1080×1440`，长图校验为 `1080px` 宽和布局计算出的实际高度。
- 全部页面成功后才原子安装最终目录；任一页面失败、超时或无效时清理临时目录并返回非零退出码。

## 错误与交付边界

输入、语法、文件系统、渲染器和 PNG 校验错误都应写入 stderr，并以 `[错误]` 开头。成功时 stdout 报告页数和每个 PNG 的绝对路径。SVG 和临时 Markdown 只用于中转，不属于交付物，也不得留在最终输出目录。
